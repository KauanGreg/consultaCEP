# consultaCEP

O consulta CEP é um programa desenvolvido para apresentar informações de um endereço a partir de um CEP fornecido.

O sistema utiliza de uma conexão API pública para consulta de CEP e cria um arquivo JSON com as informações coletadas. Ele modela os dados obtidos e apresenta ao usuário apenas informações relevantes do seu endereço.

Esse programa foi desenvolvido durante os meus estudos em Java, conexões HTTP e conceitos de API

Tecnologias Utilizadas

* Linguagem Java
